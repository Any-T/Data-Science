# 📊 Data Science Capstone Project – IBM Certification

This repository contains my final capstone project for the IBM Data Science Professional Certificate.  
The capstone applies end-to-end data science methodologies on a real-world dataset. The purpose is to demonstrate practical skills in data analysis, visualization, and machine learning.

---

## 🚀 Project Overview

This project follows the complete data science workflow:

- Data collection from APIs, web scraping, and datasets  
- Data wrangling and preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature engineering  
- Predictive modeling and evaluation  
- Data visualization and insights communication  

The goal is to extract meaningful insights and build models that solve a real-world problem.

---

## 🧠 Project Statement

The objective of this capstone project is to predict whether the Falcon 9 first stage will land successfully using historical launch data.

SpaceX advertises Falcon 9 launches at a cost of approximately $62 million, significantly lower than other providers, whose launch costs can exceed $165 million. This cost advantage is largely due to the ability to recover and reuse the first stage of the rocket. However, successful landing is not guaranteed and depends on various mission parameters.

By developing a machine learning model to predict landing success, this project aims to provide a data-driven approach to estimating launch costs and understanding the key factors that influence reusability.

## 📂 Repository Structure

1. **Data Collection & Inspection** – Gather data using APIs and perform initial exploration.  
2. **Web Scraping** – Extract Falcon 9 historical launch records from web sources.  
3. **Exploratory Data Analysis (EDA)** – Identify patterns and define labels for supervised learning.  
4. **Database Integration (SQL)** – Load data into a Db2 database and execute SQL queries for analysis.  
5. **Feature Engineering & EDA** – Prepare features to predict first stage landing success.  
6. **Geospatial Analysis (Folium)** – Visualize and analyze launch site locations and geographic patterns.  
7. **Machine Learning Pipeline (`ml_pipeline/`)** – Data preprocessing, label creation, train-test split, hyperparameter tuning, and model evaluation (SVM, Decision Trees, Logistic Regression).
